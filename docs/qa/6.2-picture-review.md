# Gate 6.2 — Photograph and caption review (owner)

> **Scope:** the 29 photographs slice 6.1 built into `public/pictures/`, and the
> captions the Gallery will show. This is the gate that decides what goes on the
> internet under your name, so it is deliberately a *reading* task, not a QA
> pass — nothing here needs the dev server.
>
> **What this gate is *not*:** the Gallery app itself (that is 6.4, and it is
> blocked by this) or its icon (6.3, already built). You are reviewing the
> *set* and the *words*.
>
> **Everything below is reversible in one line.** Pulling a photograph means
> deleting its entry from the `PHOTOS` allow-list in
> `scripts/build-pictures.mjs` and re-running `npm run pictures` — the script
> deletes the orphaned files itself.
>
> **Verdict key:** `[x] Pass` · `[!] Needs change` · `[?] Unsure / discuss`

---

## 0 · How to look at them

No server needed. The shipped copies are in `public/pictures/`:

- `<id>.jpg` — the viewer copy, bounded to 1200×900
- `<id>-thumb.jpg` — the 192×144 grid thumbnail

Open the folder in Explorer at Large Icons and you have the grid the Gallery
will show. `scripts/pictures-manifest.tsv` lists every id, group and shipped
size.

**What 6.1 produced:** 29 photographs, 58 files, **4.34 MB** total (ADR-013 §9
budgets 4–5 MB). Sources were 26.7 MB. All metadata is stripped — no EXIF, no
GPS, no camera serials in anything shipped.

## 3 · What 6.1 guarantees, so you do not have to check it

Recorded so this gate stays about the photographs rather than the pipeline:

- **The allow-list is explicit and never globs a directory.** The 29 entries
  are typed out in `scripts/build-pictures.mjs`. A file dropped into
  `assets-src/` cannot ship by accident.
- **The script refuses to run** if any entry's path matches tattoo reference
  material, the AI concept sheets, the character-QA screenshots,
  `docs/projects/**` or anything named "client". Proved by poisoning the list
  with `tattoo01.jpg` — it exits 1 and writes nothing.
- **No AI concept sheets and no client material ship.** Neither is in the list.
- **All metadata is stripped** — measured: 0 of 29 shipped files carry EXIF,
  XMP or ICC. (Worth knowing: 0 of 29 *sources* carried EXIF either, so no GPS
  was ever at risk here. The stripping is still correct, and matters the moment
  a photograph is added straight off a phone.)
- **Re-running is idempotent** — byte-identical output, `git status` clean.
- **`assets-src/` is now gitignored, not merely untracked.** It was one
  `git add -A` away from committing 27 MB including the tattoo references.
- **No new build step.** `npm run build` is still a plain static export; the
  images are committed. `npm run pictures` is run by hand when the set changes.
