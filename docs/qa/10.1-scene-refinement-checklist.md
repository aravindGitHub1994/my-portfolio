# Gate 10.1 — `scene-refinement` sign-off checklist

**For the owner, on a production static export, on real hardware.** This is the
last gate on the branch (plan-0010 §8.3). Everything in ADR-013 is built; what is
left is the set of judgements no agent can make and the measurements headless
cannot take.

**How to run it:**

```
npm run build
npx serve out -l 3005      # a dev server is NOT the thing to judge —
                           # __experienceState, __armPose, __sipNow, __fidelity
                           # and the perf counter are all stripped from a build
```

Then **clear all three localStorage keys** (`w98-intro-seen`, the tier key, the
static-floor key) so you get a first-time visit. DevTools → Application → Local
Storage → clear for `localhost:3005`.

## 8 · Still open from gate 9.2 — explicitly NOT closed by this branch

None of these are regressions and none block the merge. They are listed so the
branch closes with an honest ledger rather than a silent one.

1. [ ] **The audio mix has never been heard by a human.** Levels, `MIN_CLACK_GAP_S`,

       surface on the site.**
2. [ ] **The mobile shell has never run on a real phone** — only headless Chromium
       at 360×640 and 390×844. Untested by construction: real touch-drag
       swipe-to-close, iOS Safari's dynamic viewport, the LinkedIn in-app webview.
3. [ ] **The fidelity ladder has never been paced by a human.** At a pinned 20 fps

       too patient to sit through.

## 9 · Things deliberately left alone — say if you disagree

Not defects; decisions or accepted costs. Each is cheap to reverse and none was
reversed without asking.

- **The painter's Gallery suggestion is unreachable.** The CRT can never show a
  window body — undocking requires every window closed or minimized, and the
  painter skips minimized windows. You chose to keep the ~90 lines (2026-07-30).
  ADR-013 §9a records it so no future slice is planned around painting a window.
- **The arm is nearly straight at the far end of every reach** (94–96 % extension
  for power, mouse and mug) because the shoulder is a fixed point. Levers if it
  ever reads as a mannequin: move the props closer, or let the shoulder
  *translate* — the second is a change to the rotations-only contract.
- **`lean` rests with the hands lifted and drawn back**, not on the desk: a pose
  move is one slerp with no arc control, so any hand travelling below keycap
  height sags through the keys.
- **Single-`scale` window drag has ~5 % x error**; keyboard undock can leave
  progress a few thousandths past the rest point.
- Self-noted nits nobody has flagged: shaft billboards pale edge-on, chair
  backrest plain boxes, faint CRT moiré.
- Committer identity resolves to your work email. Mentioned twice, left alone.
