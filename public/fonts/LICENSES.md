# Font licenses

Zero Microsoft fonts ship (ADR-012 §10). Both faces below are open-licensed
period-style fonts fetched from the Google Fonts repository
(github.com/google/fonts), each under the SIL Open Font License 1.1 —
full license text sits beside each font file.

| File | Family | Author | License |
|---|---|---|---|
| `Silkscreen-Regular.ttf` | Silkscreen | Jason Kottke | SIL OFL 1.1 (`Silkscreen-OFL.txt`) |
| `VT323-Regular.ttf` | VT323 | Peter Hull | SIL OFL 1.1 (`VT323-OFL.txt`) |

Usage: Silkscreen is the Win98-pastiche shell chrome face; VT323 is the
text-mode/POST/terminal face.
